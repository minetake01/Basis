## Spout2 (Windows backend)

When built with `Native~/build-win-x64.ps1`, this package links Spout2 source from
[leadedge/Spout2](https://github.com/leadedge/Spout2) (BSD 2-Clause).

Spout2 is **not** committed to this repository; clone it into `Native~/third_party/Spout2`
via the build script before compiling `basis_mediastream_native.dll`.
